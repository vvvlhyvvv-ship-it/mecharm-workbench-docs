## 1. 产品定位（一句话）

给**无编程背景的产线操作员**用的三维示教工作台：把 STEP 模型扔进来，在模型上点出关键点位，软件自动生成路径并做碰撞校核，校核通过后一键下发给 PLC——软件只"请求"，运动控制归 PLC，软件不越界。

## 2. 用户与场景

| 项 | 内容 |
|---|---|
| 目标用户 | 锻造压机产线操作员（非互联网/非编程背景） |
| 使用设备 | 车间工控机 + 鼠标（可能戴手套，按钮要大） |
| 核心场景 | 换模具后重新示教取放料点位 → 生成路径 → 校核 → 下发 |
| 本期目标 | **只做软件功能本身**，投标取证材料（截图/视频/规格表）不在本任务包范围 |
