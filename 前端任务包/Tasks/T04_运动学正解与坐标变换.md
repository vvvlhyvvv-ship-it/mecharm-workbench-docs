# T04 运动学正解与坐标变换

## 目标
`core/kinematics.py`：桁架移动副+关节回转副串联正解、三坐标系变换（模型↔设备↔场景）。**纯 Python 可单测，不碰界面不碰通讯。**

## 前置阅读
03 架构 §3 签名 ｜ S-1 契约第 7 章（坐标系与单位约定，含 7.4 数据形态最高危项）｜ 规程 W-4.2（关节映射四要素）/W-4.3

## 步骤
1. `fk(joint_values:dict[str,float])->dict[str,Transform4x4]`：按 machine.yaml 的 axes+links 串联链式变换；输出每部件位姿
2. 坐标变换三函数：`model_to_device` / `device_to_scene` / 逆变换（场景原点、Z 向按 S-1 契约第 7 章）
3. `check_limits(joint_values)->list[Violation]`：行程逐项校验，越界含轴号/值/限值
4. 轴耦合（两型，配置驱动，非硬编码）：`sync` 型=龙门双驱 group 内同步偏差 > sync_tol_mm 时报 Violation；`ratio` 型=倍速链，从动轴位置 = 主动轴 × ratio（如 X3 三级筒 1:2，fk 展开位姿时按配置换算，**禁外部按两倍行程反推**——2026-09-15 G11 口径）
   - ⚠️ **`master` 自指必须先判（2026-09-16 T03 交付后定案，见 03 §4"实机轴系口径"）**：`machine.yaml` 实测 X3 = `{type: ratio, master: X3, ratio: 2.0}`——**master 指向自身**，因为倍速链主动件（二级筒／伸缩油缸）**不是** 22 轴清单里的受控轴，无第二根轴可指。判读规则：**`master == 自身` ⇒ 驱动级倍速**，按「该轴工程位置 = 自身驱动位移 × ratio」展开；⛔ **禁**读成「X3 = 另一根轴 × 2」的**跨轴约束**（错的跨轴 master 会静默混进 fk 一路带到现场）。只有 `master != 自身` 时才按跨轴口径。ratio 换算**必须配置驱动、禁在代码里写死 `* 2`**——终局依据＝踏勘确认清单第 4 项回执（软件下发三级筒实际位置，还是由 PLC 按下发值换算），回执后**只改 `machine.yaml`、不改本单代码**
5. 工程值/原始值换算挂这里：`raw_to_eng(axis, raw)->mm|deg`（scale+zero_offset+direction 三参来自配置）
6. pytest 已知用例：①全零位→各部件位姿=理论值 ②单轴走满行程端点 ③越界注入→Violation 命中轴正确 ④往返变换误差 <1e-6
   - ⚠️ **T03 交付实况（2026-09-16 合并，直接影响用例①的手算口径）**：① `links` 的 `length_mm` **全部为占位 `0.0`**（待契约 Q-11 图纸回执）→ 手算须按「各级只有轴位移、**无连杆偏置**」的口径，别把占位值当真连杆长度；② 22 轴**全标 `pending: true`**，`travel` 为统一占位（移动副 `[0,1000]` mm、回转副 `[-180,180]` deg）→ 加载器**只告警不拒绝**，告警在 `cfg.warnings`，**禁**把它当错误处理，也**禁**据占位行程对外承诺可达性结论；③ 配置入口＝`from core.config import load_machine`（T03 已包化为 `core/config/`，调用形态不变）
