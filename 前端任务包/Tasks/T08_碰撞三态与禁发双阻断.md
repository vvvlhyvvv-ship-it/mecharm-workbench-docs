# T08 碰撞三态与禁发双阻断

## 目标
`core/collision.py`：路径沿线的干涉检查（机械臂各部件 vs 工件/模具/周边设备），三态判定+高亮定位；**干涉结果硬锁步骤⑤下发**（按钮禁用+函数内二次校验）。步骤④完整可用。招标 16(3)②③ 的正面回应单。

## 前置阅读
02 设计方案 §2 步骤④ ｜ 03 架构 §3 签名 ｜ 01 需求 R-6 ｜ 招标 16(3)②③

## 步骤
1. 判定：路径按步长离散采姿态（步长=machine.yaml `limits.path_sample_step_mm`，样例配 50；姿态由 T07 的 ik 逐采样点求关节值→fk 得出），每姿态对臂身包围盒做粗筛（AABB），命中者用 **OCC 距离算法**（BRepExtrema）算最小距离真值
2. 三态：d≤0 干涉 / d<clearance_warn_mm 预警 / 其余通过；结果 CollisionResult{verdict, cases:[{seg_id,part_a,part_b,min_dist_mm,point}]}
3. UI：[开始校核]→三态卡片；干涉列表点击行→视口定位+双方红色高亮+顶部红条（文案见 02）；🟡预警允许进⑤但弹窗内显示黄条警告
4. **双阻断**：⑤按钮 disabled 状态 + `send_path()` 函数入口重新读校核状态并独立复判（校核结果带路径指纹 hash，路径改动 hash 失配也拒发）——两条拦截各留日志
5. 性能：单条 20 段路径校核耗时打日志；OCC 精判过慢则启用 FCL 宽相（需先按 §8 走组件引入，禁直接 pip 装）
6. pytest：三态用例集自造（两个 BOX 相交/间隙 5mm/间隙 500mm → 🔴🟡🟢）；hash 失配拒发用例
