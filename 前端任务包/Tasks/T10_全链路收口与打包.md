## 前置阅读

> ⚠️ **入口引导（T01 已交付 `app/bootstrap.py`，本单不必自己写；但打包入口必须显式调）**：`import app`／`app.*` 已自动预载 Windows 系统 ICU，走 `app` 包的入口**无需任何 ICU shim**；**但从 `app` 包外直接 import PySide6 的入口必须显式** `from app.bootstrap import preload_windows_icu`（放在 PySide6 之前）——**本单的典型情形就是 PyInstaller 入口脚本／`.spec` 里自建的 entry**（不 `import app` 起手时）。
> **成因（实测）**：conda 的 `icu` 包在 `%PREFIX%\Library\bin` 也放了一份 `icuuc.dll`，conda 的 python 启动时自动把该目录加入 DLL 搜索路径 → `Qt6Core.dll`（**静态**导入表含 `icuuc.dll`）先命中它，符号集不符报 **WinError 127**（`ERROR_PROC_NOT_FOUND`），表现为 `from PySide6 import QtCore` 直接失败；`icu` 是 `libxml2`（OCCT 的 XML 支持链）硬依赖，**不能移除**。
> ⛔ **禁复制粘贴自写 shim**（唯一写者＝T01，见 04 §4 矩阵该行）；`dist` 包起不来且报 WinError 127 时，**先查打包入口有没有调 `preload_windows_icu`**，不要改 `app/bootstrap.py`。

## 步骤
1. 下发流：`send_path()` 通过后→确认弹窗（摘要+"请求值"小字）→写段+命令字→右栏握手五段进度可视化→执行
2. 实时联动：客户端 `on_frames`→关节值（raw_to_eng 换算）→fk→`pose.update` 推视口；渲染端线性插值到 60fps；角标显示实测数据频率（**<10Hz 变黄+人话提示，禁外推**）
3. 模式互斥：播放动画=[仿真]，UA 数据驱动=[联动]；两态下 UI 可编辑性按 02 §3（联动中禁编辑点位，需先"暂停跟随"）
4. 异常路径实测（规程 W-6.4）：执行中断线→状态灯灰+日志+模型停住不跳飞；PLC 拒绝→红条+原因码+[查看日志]；数据越界→丢弃该帧并计数
5. 工程文件 `core/project.py`：save/load JSON（$schema=proj/v1；含点位/路径/校核结论快照/配置版本号），加载旧版本工程→按版本兼容策略迁移
6. 打包：PyInstaller onedir（含 view/ 静态资源与 config/），`dist/` 产物在**本机干净目录**双击 exe 全流程走通一遍。⚠️ conda 版 OCC 动态库/数据文件收不齐是已知坑：用 `--collect-all` 或自定义 hook 收全，卡住**停下汇报**，不许砍功能绕路
   - ⚠️ **打包入口必须显式引导 ICU**（见本卡"前置阅读"下那条）：若 PyInstaller 的入口不是 `import app` 起手（自建 `run.py`／`.spec` 里的 entry），**第一行必须** `from app.bootstrap import preload_windows_icu` 并调用 → 否则 `dist` 里同样会因 conda `icu` 的 `icuuc.dll` 被 `Qt6Core.dll` 先命中而 **WinError 127 起不来**。这属"dist 包双击启动"验收项，**不得以开发机上 `python tools/smoke.py`／任何 `import app.*` 的脚本能起来充当证据**（那两条路都已有引导，`dist` 的入口是第三条路）
7. 全链路冒烟脚本 `tools/e2e_smoke.py`：自动跑"导入测试模型→3 点→路径→校核→模拟器下发→跟随 10s"，断言各步完成
