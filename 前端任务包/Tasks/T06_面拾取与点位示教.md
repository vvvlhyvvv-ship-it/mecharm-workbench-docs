# T06 面拾取与点位示教

## 目标
视口点击模型面→回传 mesh_id+face_id→core 换算真实 3D 点+法向→右栏点位列表管理。步骤②完整可用。

## 前置阅读
02 设计方案 §2 步骤② ｜ 03 架构 §5（pick.face 协议）｜ T05 完成

## 步骤
1. `view/js/pick.js`：raycaster 拾取，命中回传 `{mesh_id,face_id,u,v}`（三角形重心坐标）；悬停面高亮、点击落标号牌（序号+名称，标签随相机距离保底字号）
2. `core/geometry.py` 增补：`face_point_from_tri(mesh_id,face_id,u,v)` 与 `face_center(mesh_id,face_id)`（法向从 B-Rep 面真值取，不是三角形法向）
3. 点位数据模型：`Waypoint{id,name,pos_mm,normal,source_face}`；列表 UI（增删改命名、手改坐标、非法值拒绝、删除不重排序号）接真数据
4. 拾取模式与视角旋转的鼠标手势分离：左键=取点，右键/中键=旋转平移，滚轮=缩放；右栏顶部固定提示"在模型上点击机械臂要到达的面"
5. pytest：给定三角形+重心坐标的手算换算用例 3 组；法向与 B-Rep 面法向一致用例
