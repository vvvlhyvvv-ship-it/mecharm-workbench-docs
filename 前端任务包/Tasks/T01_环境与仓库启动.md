# T01 环境与仓库启动

## 目标
建全新代码仓 + Python 环境（含 OCC），装成即停，产出可复现的环境清单。**不写任何业务代码。**

## 前置阅读
03 架构 §6 环境表 ｜ 01 需求 D-1 D-8

## 步骤
1. `git init "E:\ZCode项目\机械臂工作台"`，建 `.gitignore`（`__pycache__/`、`.venv/`、`dist/`、`build/`、`*.log`），目录骨架：`app/ core/ comm/ view/ config/ tests/ tools/ evidence/`（各放占位 `__init__.py`/README；`evidence/` 存各单验收截图，入库留痕）
2. 装 Miniforge 到 `D:\Miniforge3`（静默安装 `/S /D=D:\Miniforge3`）；`conda create -n mecharm python=3.11 -y`
3. 装依赖并锁定：
   - conda-forge：`pythonocc-core`
   - pip（进 mecharm 环境）：`PySide6 pyyaml numpy asyncua pytest`
   - three.js：下载 r160+ 的 `three.module.js` 本地文件放 `view/vendor/`（禁 CDN 运行期引用）
4. `conda env export > environment.yml` + `pip freeze > requirements.lock.txt` 入库
5. 冒烟脚本 `tools/smoke.py`：import OCC（OCP）、PySide6、asyncua、numpy 各打印版本
6. commit：`chore(T01): 环境基线`

## 完成标准
