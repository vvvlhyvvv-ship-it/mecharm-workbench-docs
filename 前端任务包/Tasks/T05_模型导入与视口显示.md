## 目标
`core/geometry.py`：STEP/IGES/STL 导入（OCC）、装配树还原、B-Rep/网格判定、tessellation 推给视口渲染。**这一步做完，软件就能"把模型扔进去看得见"。**

**2026-09-15 口径扩充（随 CR-2026-03，依据《三维模型导入能力综合技术方案》及其《审阅意见 V1.0》，@user 指示按建议调整）**：
①全部文件走**原生转换链**，**不引入前端 WASM 直解路径**（04 §7.2-G14）；

③**双缓存**（.brep 几何真身 + 轻量化网格，源文件哈希为键，二次导入秒开）；
④三阶段进度（解析 / 三角化 / 优化）；

## 步骤
1. `import_model(path)`：OCC 读 STEP/IGES（XCAF 保装配关系），STL 走网格分支；返回 Assembly{tree,is_brep,stats}；中文路径实测（失败则加短路径缓存层）
2. `tessellate(assembly, deflection)`：按部件出 MeshPart（顶点 float32/索引 uint32），**同时落 `face_map`（三角形→B-Rep 面 ID 映射表，随部件留存 core 侧）**——这是 T06 取真值法向的唯一依据，不落此表 T06 做不了；base64 经桥 `mesh.load` 推视口（分批推，见 03 §5 传输预案）
3. **转换链与内存纪律**（吸收方案 §3.3/§4-1）：三角化（弦高容差可控，暂定 0.3–0.5mm）→ 简化 → LOD 分级 → 轻量化网格；**单次通过：三角化完成立即释放 XDE/B-Rep**。弦高容差值走 `machine.yaml` limits 节 `tessellate_deflection_mm`（**随 T03 样例提供**，禁散写字面量）
4. **双缓存**（吸收方案 §3.3/§4-5）：键 = 源文件哈希；①`.brep` 二进制缓存——几何真身，供 T06 拾取真值与 T08 精判**按需重载**（免重新解析 STEP，用毕可释放）；②轻量化网格缓存——显示用。**命中即免转换，二次导入秒开**；缓存命中不跳过 is_brep 判定与日志留痕
   - **落盘路径＝`machine.yaml` 的 `paths.cache_dir`**（T03 提供，默认 `%LOCALAPPDATA%\mecharm\cache`；**2026-09-15 第六轮审计补口径**）：**禁落仓内**、禁把仓内相对路径写死进代码；`.gitignore` 已含 `cache/`、`data/`、`*.brep` 作双保险。**理由**：缓存里是**甲方模型的几何真身**，而远端为**公开仓**（04 §7.1-10 实测），一次目录级 `git add data/` 就等于把甲方几何推上公网。
   - **缓存目录不可用**（不存在／无写权限）→ **降级为不缓存并告警**，**绝不回落到仓内目录**（禁写"找不到就写 `./cache`"这类兜底）。
5. 视口 `view/js/loader.js`：接收 MeshPart 建 three.js 场景（材质深色规范见 02 §4）；左栏装配树接 Qt 原生 Tree（数据=tree），单击=高亮消息 `hl.set`、双击=相机飞到；**按工位/区域按需加载，严禁整线模型全量常驻**
6. UI 接线：步骤①页接真流程（拖放→**三阶段进度条：解析 / 三角化 / 优化**→"✓ 实体模型/✗ 面片模型"→统计行）；is_brep=False 时步骤②保持锁；**导入成功时调 `stepbar.mark_completed(1)`**（⚠️ **T02 遗留 F1，2026-09-16 收单登记**：T02 壳内回看态无触发点，本单是第一个能产生"步骤完成"事实的单——不调此调用，02 §1"点已完成步骤可回看"永远不可见；见 99 台账 T02 行备注 F1）
7. **固定设备离线预处理管线**（吸收方案 §3.2；新承接项，04 §7.2-G12）：压机/机械臂/加热炉/液压站/产线工装等固定设备，交付前一次性预处理为资产库（轻量化网格 + LOD×3 + 碰撞代理 + .brep 缓存），随安装包交付；工具脚本放 `tools/`（**新增文件名先报备**）；暂定目标：单件资产 ≤10MB、整线 ≤500MB（**暂定，P0 实测锁定**）。**落盘根目录＝`paths.cache_dir` 下的 `assets/`（仓外）**——随安装包交付的是**打包产物**，**资产库本体不入 git**（远端为公开仓，见 04 §7.1-10）
8. **P0 导入性能实测**（04 §7.2-G15）：用真实大模型（优先客户真实 STEP；无则用自造模型起步）记录**解析耗时／峰值内存／三角面数／几何面数／曲面类型分布／二次导入耗时**，数字进日志。**本项不阻塞本单主体开发，但阻塞对外规格承诺——P0 完成前任何导入性能数字（如 ≤120s@200MB、二次导入 ≤3s）均为暂定值**（审阅意见 §四）
9. pytest：装配树层级数与构造样例一致；STL 判定 is_brep=False；缺失引用面不崩；缓存键命中/失效用例（源文件内容变 → 哈希变 → 重新转换）
