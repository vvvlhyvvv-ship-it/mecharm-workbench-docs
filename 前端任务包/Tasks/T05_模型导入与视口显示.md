# T05 模型导入与视口显示

## 目标
`core/geometry.py`：STEP/IGES/STL 导入（OCC）、装配树还原、B-Rep/网格判定、tessellation 推给视口渲染。**这一步做完，软件就能"把模型扔进去看得见"。**

## 前置阅读
03 架构 §3 §5 ｜ 02 设计方案 §2 步骤① ｜ 招标 16(1)(2) 原文（在 01 需求 §5 追溯表）

## 步骤
1. `import_model(path)`：OCC 读 STEP/IGES（XCAF 保装配关系），STL 走网格分支；返回 Assembly{tree,is_brep,stats}；中文路径实测（失败则加短路径缓存层）
2. `tessellate(assembly, deflection)`：按部件出 MeshPart（顶点 float32/索引 uint32），**同时落 `face_map`（三角形→B-Rep 面 ID 映射表，随部件留存 core 侧）**——这是 T06 取真值法向的唯一依据，不落此表 T06 做不了；base64 经桥 `mesh.load` 推视口（分批推，见 03 §5 传输预案）
3. 视口 `view/js/loader.js`：接收 MeshPart 建 three.js 场景（材质深色规范见 02 §4）；左栏装配树接 Qt 原生 Tree（数据=tree），单击=高亮消息 `hl.set`、双击=相机飞到
4. UI 接线：步骤①页接真流程（拖放→进度→"✓ 实体模型/✗ 面片模型"→统计行）；is_brep=False 时步骤②保持锁
5. 导入耗时实测：用 20MB 级自造 STEP 压一次，数字进日志（性能留痕，不做指标承诺）
6. pytest：装配树层级数与构造样例一致；STL 判定 is_brep=False；缺失引用面不崩
