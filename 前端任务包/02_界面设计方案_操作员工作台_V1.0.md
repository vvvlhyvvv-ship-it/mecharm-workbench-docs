## 1. 全局骨架（一屏无滚动；舞台＝固定逻辑尺寸＋等比缩放）

```
启动序列：载入页（≤4s，真实初始化日志逐行打钩）→ 登录页（工号/姓名，不校验）→ 主界面
         （三者＝MainWindow 内 QStackedWidget 原地切换；载入/登录恒 1920×1080 逻辑尺寸、不进 wide 档）

┌──────────────────────────────────────────────────────────────────────┐
│ 顶栏 56px：品牌区│菜单组(三维导入/装配体模式/测量/报警与日志)│使能(禁用)│
│           数据芯片(fps/Hz/ms)│双灯(链路+轨迹判定)│用户盒            │
├────────────┬──────────────────────────────────────┬──────────────────┤
│ 左栏 页签   │        3D 视口（WebEngine 内嵌）       │ 右栏 常驻         │
│ ①装配树     │  浮层：报警红条／干涉高亮条＋脉冲圈      │ 工作头面板        │
│ ②编程       │                                      │ ＋机构与关节      │
│ ③路径仿真   │                                      │ （22 轴分组）     │
├────────────┴──────────────────────────────────────┴──────────────────┤
│ 底栏 32px：状态一句│模型计数│投标水印│…│版本（频率角标 Hz/fps 保留）     │
└──────────────────────────────────────────────────────────────────────┘
```

- 舞台档位：std 1920×1080（字号系数 1）/ wide 2560×1080（系数 1.56，窗口宽高比 ≥2.0 自动选）；`--stage` 可强制；1366×768 等比缩放不裁切（原 V1.x「最低兼容 1366×768」口径不变）
- 步骤条（StepBar）**退役为薄壳**：导航职责移交左栏三页签；步骤完成态由页签徽标＋页内四步流水线指示表达（对齐台账 L-7）
- 左右栏宽：std 365/384 px、wide 460/490 px（取字面值）
- 顶栏**无「手动/半自动/全自动」模式组**（三模式管理归 PLC，S-1 §3.2.1；蓝图 Δ-1）；「使能」按钮渲染但恒禁用＋「待契约回执」（Δ-11，点表未收 enable_mask）
- 取证档：`--ui-profile evidence` 启动时公司名/水印/招标编号等一律占位文案（红线 12 边界；蓝图 §1-9）
- 折叠钮（左右栏）保留（演示稿无此元素，小屏唯一腾视口手段；蓝图 Δ-10）

## 2. 页签与面板界面规格（细目以蓝图 §3.4/§3.6 为准）

### 2.1 装配树页签（承旧「左栏装配树」＋增强）
- 多级树：单击高亮、双击视角飞到；干涉件整行红标（颜色＋图标＋文字三通道）
- 工具行：删除选中（未选中禁用）/删除整组/清空全部模型（清空类二次确认）
- 「选中件装配」三选（固定/关节绑定/自由）＋绑定到〈轴〉：渲染但禁用＋「待后续版本」（Δ-9：links 数据占位 0.0，不在占位数据上承诺姿态）

### 2.2 编程页签（承旧「步骤①导入／②选点／③路径」语义，交互冻结口径不变）
- 顶部四步流水线指示（①导入模型→②选择面→③生成轨迹→④PLC 输出；done/now 由真实状态驱动，**仅指示不导航**）
- 取点交互沿用 T06/T07 冻结行为：半透明操作态、悬停面高亮、点击取点落标号牌、红框拒非法值、超行程校验、点位/路径失效机制；**工作模式未选定 ⇒ 取点区锁定**（G16 前置语义不变）
- 工具区：**段型二选一（点位型＝空程快速／轮廓型＝作业速度，速度只读 machine.yaml limits）＋连续过渡复选框（默认未勾选；电Q-8 回执前只随段携带标志位并给人话告警）**——V1.2 冻结口径原样保留；切换段型/连续过渡 ⇒ 已生成路径作废；选点偏移 mm；保存/导出 JSON/导出 CSV/导入/清空（清空二次确认）；插入动作按钮组渲染但禁用（待工艺口径）
- 底部「生成并校验轨迹」（＝生成路径＋自动校核合并）→ 校验结论行（通过/不通过 · N 处干涉 · 下发许可，三通道）；「下发执行」＝**跳转路径仿真页签**（不做第二套下发，Δ-4）
- 三维导入经顶栏「三维导入」唤出**浮层**（拖拽区＋选文件兜底＋三阶段进度＋结果读数；认领规则/规格清单期 3）
- PLC 输出区（页签底部，T17）：工步数据表/变量映射 CSV、ProcessStep 预算、SCL 灰置「待电气方确认后开放」；用途声明三串逐字照蓝图 §6.3

### 2.3 路径仿真页签（承旧「步骤④碰撞校核／⑤下发 PLC」语义，判定与禁发语义不变）
- ①时间轴·预演：红绿带＝校核结果（可行绿/干涉红）、刻度＝目标点分界、游标随播放；标注「只动画面，不下发」；预计时长恒带「**估算**」
- ②执行控制：⇩下发执行＝确认弹窗（摘要＋固定小字「下发 = 向 PLC 提出运动请求，PLC 会再校验并有权拒绝或限速」）＋九步握手五段进度＋异常红条（越界/拒绝带原因码/断线），**语义与 V1.x 步骤⑤一字不改**；继续/暂停/停止/复位四命令实做（停止/复位用现成包装，暂停/继续按蓝图 §6.2 授权增薄包装）；倍率＝SpeedOverride 实做；软件侧「**连续/逐段**」二选一（⛔ 不叫手动/半自动/全自动，Δ-1）
- ③干涉清单：按设备归并＋干涉对明细（零件对/最小时距/步号）＋阻断式干涉报警模态（行点击→视口定位＋双方高亮；关闭不改变禁发状态）
- ④轨迹清单表：目标点级/全部插补步切换、只看干涉开关、点行→3D 定位
- **禁发双阻断不变**：存在干涉步 ⇒ 按钮禁用＋人话原因＋下发函数内真二次校验（T08 冻结语义）

### 2.4 右栏常驻双面板（新设；替代旧「右栏上下文五页」，不随页签切换）
- 工作头面板：五臂列表（machine.yaml `modes`）＋★当前主工作头；**沿用 G16 语义**——未选定锁「编程页签取点区」，切换二次确认并作废已有点位/路径/校核；行程范围按该模式轴 travel 汇总（真值），额定负载/末端形式无数据显「—」
- 机构与关节：22 轴四组（共用机构/当前工作头/安装架/未建模机构）；**回读仅 8/22**，其余恒「—」＋「点表未收」（禁因在线显 0.0）；轴点动整块禁用（期 3）；软限位提示行（无回读的轴不计入）

- 圆角**分层**：模态/浮层 8px、常规控件 5px、小控件 4px、徽标胶囊 999px、卡片 0（无圆角）——V1.x 隐含「统一 8px」废止

- 状态＝颜色＋图标＋文字**三通道**（手套/色弱不靠颜色单独说话）

## 5. 占位与降级

- 未接内核的功能一律**渲染但禁用＋如实提示**（「待后续版本」「待契约回执」「待电气方确认」），不假装能用
- 视口加载失败：Qt 侧显示错误卡＋日志，不白屏死循环
- 装饰性动效可整体关闭（`motion_enabled`）；无 backdrop-filter 环境以近不透明实底替代毛玻璃
- 界面文案（水印/品牌/登录预填/声明文案等）一律读 `config/ui.yaml`，代码零字面量；取证档 `--ui-profile evidence` 一键切占位文案
