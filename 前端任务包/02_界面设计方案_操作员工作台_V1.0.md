## 1. 全局骨架（一屏无滚动，1920×1080 工控机为基准，最低兼容 1366×768）

```
┌────────────────────────────────────────────────────────────┐
│ 顶栏(56px)：软件名 │ ①导入 ②选点 ③路径 ④校核 ⑤下发(步骤条) │
│                                    模式徽标[仿真/联动] 在线灯│
├──────────┬──────────────────────────────┬──────────────────┤
│ 左栏     │                              │ 右栏(360px)      │
│ 装配树   │   3D 视口（WebEngine 内嵌）   │ 上下文面板       │
│ (280px)  │   浮层：视角复位│报警红条     │ 内容随步骤切换   │
│ 可折叠   │                              │ 可折叠           │
├──────────┴──────────────────────────────┴──────────────────┤
│ 底部状态栏(32px)：人话日志一行滚动 │ 数据频率角标 │ 版本     │
└────────────────────────────────────────────────────────────┘
```

- 步骤条即导航：当前步高亮；前置未完成置灰不可跳（防漏校核）；点已完成步骤可回看。
- Qt↔视口全部经 bridge（03 架构 §5 协议），右栏面板=Qt 原生控件（不是网页）。

## 2. 五步界面规格（右栏上下文面板逐一定义）

### 步骤① 导入模型
- 视口空态：居中提示"把 STEP / IGES / STL 文件拖到这里"（支持拖放 + 右栏大按钮[选择模型文件]兜底）
- 导入中：进度条 + "正在读取模型…"；完成后依次显示：
  - "✓ 实体模型（可拾取、可算碰撞）" 或 "✗ 面片模型（不能用于编程）"→后续步骤保持锁定
  - 统计行：零件数 / 面数 / 耗时
- 左栏装配树两级折叠：单击=视口高亮该零件，双击=视角飞到
- 日志人话模板："已导入 机架.step，47 个零件，实体模型 ✓"
- 禁止上屏：AP242、B-Rep、wasm、tessellation 等一切术语

### 步骤② 选取点位
- 进入后模型转半透明操作态；悬停面高亮；点击=取点（视口落标号牌：序号+名称，随距离保底可读）
- 右栏点位列表每行：[序号｜名称｜X｜Y｜Z｜删除]，名称/坐标可点开手改（回车提交，非法值红框拒绝）
- [+命名当前点] 按钮；默认命名 P1、P2…；删除后序号不重排
- 提示文案固定："在模型上点击机械臂要到达的面"

### 步骤③ 生成路径
- 按钮[生成路径]；完成后右栏：段清单表（段号｜起点→终点｜类型｜长度 mm）+ 汇总行"共 N 段 · 总长 X m · 预估节拍 Y s" + [▶播放][⏸]
- 视口渲染路径折线+方向箭头；播放时机械臂沿路径动，当前段高亮
- 播放中锁定点位编辑；改动点位则路径作废并提示重新生成
- 禁止上屏：关节角矩阵、插补

### 步骤④ 碰撞校核
- 按钮[开始校核] → 三态结果卡片：🟢通过 / 🟡预警（间距小于安全值） / 🔴干涉
- 🔴/🟡 时列表：段号｜涉事部件｜最小距离 mm；点击行→视口定位干涉点、双方部件红色高亮
- 视口顶部长红条："⛔ 第 X 段与【模具A】干涉，已禁止下发"（高亮+报警条+文字三通道，16(3)③）
- 校核结果全局状态 → 决定步骤⑤按钮可用性

### 步骤⑤ 下发 PLC
- 校核非🟢或离线：按钮置灰+旁注"校核未通过，无法下发"
- 🟢点击→确认弹窗：段数/总长/目标速度/点位摘要 + 固定小字"下发 = 向 PLC 提出运动请求，PLC 会再校验并有权拒绝或限速" → [确认下发][取消]
- 下发后右栏握手进度：请求→校验→接受→执行→完成；失败红条"PLC 拒绝：原因码 X"+[查看日志]
- 执行期视口模型随 PLC 回读实时动，角标显示实测频率

## 3. 模式与状态（全局）

| 元素 | 规格 |
|---|---|
| 模式徽标 | [仿真]蓝=动画是算出来的 / [联动]绿=模型跟实机同步走。互斥常显，任何时刻用户知道模型动是真是假 |
| 在线灯 | OPC UA：绿在线/灰离线；离线时仅⑤禁用，①-④照常（离线编程可用） |
| 频率角标 | "数据 20.1Hz · 画面 60fps"；<10Hz 变黄+日志人话提示 |

## 4. 视觉与易用性硬指标（R-10 落地值）

- 深色底（车间反光环境）：背景 #16202a 系；报警红 #b3261e / 通过绿 #1c7c43 / 预警黄
- 正文≥14px、步骤标题16px、主按钮文字16px粗体、按钮高≥40px、主按钮占右栏整宽
- 状态=颜色+图标+文字三通道（手套/色弱不靠颜色单独说话）
- 删除点位、确认下发均需二次确认；所有可点元素 hover 有反馈
- 单位 mm / s / °，界面固定位置标注一次不逐行重复；全中文

## 5. 占位与降级

- 内核未就绪的步骤（T02 阶段）：右栏占位卡片写"本步骤功能开发中"，步骤条置灰逻辑照真实现
- 视口加载失败：Qt 侧显示错误卡+日志，不白屏死循环
