## 步骤
1. 按 01 蓝图 **§4-A** 逐行替换颜色 TOKENS（含新增键 `border2`/`text_faint`/`accent_deep`）；主按钮 QSS 文字色改 `#08161c`；`off_bg`/`off_text` **保留现值**（演示稿禁用态用 `opacity:.5`，Qt 无等价物，收单不判差异）
2. 按 **§4-B** 新增/改写尺寸与字号令牌：`body_px` 14→**13**、`btn_h` 40→**26**、新增 `btn_h_s`=21、`step_px`→14.5（卡片标题 h3 用 13）、`btn_px`→12（`.btn.tiny` 用 11.5）、新增 `topbar_h`=56／`status_h`=32／`tab_h`=36／`tree_row_h`=23／`s1..s4`=4/8/12/16／`fs_wide`=1.56。**这些是 std 档字面值**，wide 档倍率不在本单实现
3. 按 **§4-C** 落圆角**分层**（⛔ 不是「6→8px 全量」）：模态/浮层 8px、常规控件 **5px**、小控件 **4px**、顶栏菜单徽标 999px（胶囊）、页签徽标 8px；**卡片/面板＝0（无圆角）**——演示稿 `.card` 只有 `border-bottom`，其 `--r:8px` 虽声明但**无任何选择器引用**。若判断产品侧给卡片加圆角更好看，**须停下上报**由指挥方裁，不得自行加（自加即记 Δ）
4. 数字体：数值类控件（表格数字列/坐标/芯片读数/角标/时间戳）指定等宽字体链 `ui-monospace,"Cascadia Mono",Consolas,"SF Mono",monospace`＋等宽数字（Qt 侧 `QFont.setStyleStrategy`＋等宽族近似）；中文正文链 `Microsoft YaHei UI → Microsoft YaHei → system-ui`。**在 `theme.py` 提供唯一 helper**，界面代码不得散写字体名
5. 改写 `app/theme.py` 模块 docstring（现 `:7–8` 写「口径来源：02_界面设计方案 §4——…正文≥14px、按钮高≥40px」）⇒ 指向 **01 蓝图 V1.2 §4**，否则后人读代码会被带回旧数值。铁律段（禁散写内联样式、动态属性＋`unpolish/polish`）原样保留
6. `view/css/app.css` 同步换 token；`view/js/loader.js` 画布底色默认改 `#d9e2ea` 浅色（`--canvas`，HTML:35），网格/坐标轴/悬停高亮/路径线配色按浅底可读性适配（对齐演示稿预览图观感）。视口内深色专属元素（空态卡、标号牌、报警条）在浅底上保留深色卡片底（演示稿同款处理），对比度自查
7. 新增守卫测试：颜色/尺寸/圆角三表键完备、主按钮深字、accent 唯一性；跑全量 pytest＋e2e_smoke＋`tools/config_check.py`＋`tools/lint_no_magic.py`，**贴原始输出**
   - ⚠️ **lint 陷阱**：`lint_no_magic.py` 的 `FIELDS` 含 `direction`／`modes` 等词，且扫 `view/`。改 css/js 时若写出「字段名与数字同行」（如 `flex-direction:row` 与像素值挤在一行）会**误命中**。处置：改写代码（拆行/换写法），⛔ **禁改 lint 脚本**（非本单归属）；确属误判则连同原始输出上报
