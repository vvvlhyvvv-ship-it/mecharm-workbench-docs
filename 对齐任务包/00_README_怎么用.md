## 五、纪律承接（与前端任务包同口径，违者收单不过）

- 每单一个分支 `task/TXX`，commit 格式 `feat(TXX): <一句话>`；每单完工汇报三件事：**改了什么文件 / 怎么自测（贴实测输出）/ 遗留问题**
- 源文件 ≤300 物理行；**唯一写者**——只动本卡「文件归属」列出的文件；增件（归属外新文件）须在收单时登记理由
- **动手前先 `wc -l` 目标文件**：已满／近满 300 行的文件禁原地追加（现况 `app/shell.py`＝300、`core/collision.py`＝300、`app/theme.py`＝179），一律走卡片指定的瘦身或增件方案（审核 A-2／A-3）；新增源文件名必须在派单卡「文件归属·增件」里预先声明，未声明者⛔不得创建
- core 层每个函数必须带 pytest；`python -m pytest` 全绿＋`python tools/e2e_smoke.py` rc=0 是每单底线（e2e 判据追加按收单顺序串行合入，见 T13 卡说明）
- **e2e 双文件跨卡归属（审核 A-6 处置）**：`tools/e2e_smoke.py`（245 行）与 `tools/e2e_rig.py`（190 行）由 T12–T17 六单共用，逐单都要追加判据 ⇒ 二者列为**跨卡共享件**，唯一写者规则改为「**同卡内独占、跨卡按收单顺序串行合入**」；追加前先 `git pull` 并 `wc -l`，超 300 行即按**预授权拆分件** `tools/e2e_tabs.py`（承载 T14–T17 页签级判据）外移，无需再请批
- **并行豁免（书面）**：04 矩阵 L179「同一时刻只允许一个会话改 `app/`」——波次 1 的 T11∥T12 同动 `app/` 属**指挥方书面豁免**，条件是**文件级不相交**（`app/theme.py` 只归 T11、`app/shell.py` 只归 T12、`app/statusbar.py` 只归 T12）；其余波次仍守 04 原口径
